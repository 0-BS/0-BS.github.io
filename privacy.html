Stand: 6. Oktober 2026

Privacy policy

Last updated: 6 October 2026

  • Own mailboxes only. mail-triage accesses only the Gmail mailboxes of its operator, Adrian Rhomberg. There are no other users.
  • Purpose. Messages are read in order to label, prioritise and archive them and to send a daily summary to the operator's own address. Messages are never sent to third parties.
  • No sharing. Data is not sold, not shared and not used for advertising.
  • Services involved. Data is processed only by these services: Google (Gmail), Anthropic (Claude, to classify shortened and masked message excerpts) and ntfy (push notifications containing only counts and links, never message content). No data is stored with any other third party.
  • Local storage. A log of label changes is kept only on the operator's own computer.
  • Google API data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • This website uses no tracking, no cookies and no external scripts.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.
